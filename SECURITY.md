# Security Policy

## Private reporting

Use GitHub's **Report a vulnerability** feature in the Security tab if it is enabled. Otherwise, contact the repository maintainer privately. Please do not publish exploit details or credentials in a public issue.

Include reproduction steps, affected versions or browsers, potential impact, and any mitigation ideas. A response or remediation timeline is not guaranteed.

## Project considerations

This project is a browser-based educational art simulation, not calibrated laboratory equipment. Test both 2D and 3D views.
